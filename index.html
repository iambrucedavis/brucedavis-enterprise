I built these three personal prototypes to check sample plans and designs. They are separate from my employer work.

PAM Onboarding Readiness

Which accounts are ready for the next rollout group?

Personal project · AI-assisted · Synthetic data · Read-only

Checks whether sample accounts have owners, completed tests, and approval flags before proposing rollout groups.

My contribution: I defined what to check and built the rules, sample account list, report, and tests with AI assistance.

Keep in mind: A person must check the supplied account information before approving a rollout.

Try this: choose “Blocked” to see what each account is missing.

View example report → View code and tests ↗
Scope and context

The tool reads supplied account information; it does not change accounts. It does not discover dependencies or verify approvals and tests. A person must check the findings and approve any rollout. The optional AI connection was tested with simulated responses, not live AI calls.

Infrastructure Design Validator

What needs attention in this design?

Personal project · AI-assisted · Synthetic data · Read-only

Checks a sample design for selected network, dependency, ownership, and recovery issues.

My contribution: I defined the checks and built the sample design, validation rules, system diagram, report, and tests with AI assistance.

Keep in mind: These sample-design checks do not inspect live systems or certify an architecture.

View example report → View code and tests ↗
Scope and context

The tool reads a supplied design; it does not inspect or change live cloud systems. A technical lead must check the findings and assumptions. These checks do not certify an architecture.

Change Readiness Tracker

What is missing from this change plan?

Personal project · AI-assisted · Synthetic data · Read-only

Highlights missing prerequisites and scheduling conflicts, then compares two versions of a change plan.

My contribution: I defined the checks and built the sample plans, comparison rules, report, and tests with AI assistance.

Keep in mind: Ready for review does not mean approved to execute.

View example report → View code and tests ↗
Scope and context

The tool reads supplied change plans; it does not verify their records, approve work, or carry out changes. A person must check the findings and approve the work. Ready for review is not approval to execute.
